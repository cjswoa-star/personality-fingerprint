# 성격지문 · 나의 성향지도

성격 60문항, 관계 탐색 39문항, 상황 탐색 15문항을 통해 평소의 나·관계 속의 나·실제 상황 속의 나를 함께 살펴보는 자기이해 프로그램입니다.

현재 기준 버전: v2.3.1 한국어 문장 전면 검수본

- 성격 핵심: BFI-2 구조 기반 60문항
- 관계 39문항: 자체 개발 탐색 모듈
- 상황 15문항: 생활 장면 탐색 모듈
- 다른 사람이 보는 나: 현재 결과 파일 비교 방식, Firebase 링크 연결 방식으로 전환 예정

이 프로그램은 임상 진단, 선발, 치료를 위한 표준화 검사가 아닙니다.
